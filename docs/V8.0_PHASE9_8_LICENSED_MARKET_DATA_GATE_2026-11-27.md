# NBA AI V8.0 Phase 9.8 — Licensed market-data gate

Audit date: 2026-11-27
Branch: `v8.0-phase9.8-licensed-data-gate`
Scope: source licence/provenance review and import gate. No odds archive was downloaded or ingested. No paid API was called. No Neon data was changed. No production files were modified.

## Decision

**Historical market-data import remains BLOCKED pending explicit dataset rights and source-level attribution.** A public GitHub repository or a software licence does not by itself grant rights to redistribute the underlying sportsbook odds records.

## Source review

### 1. SportsbookReview archive (SBR)

- Repository: https://github.com/flancast90/sportsbookreview-scraper
- Pinned commit: `1a820e50c6fbd0276cde073c22bfffae78930868`
- NBA archive object: `data/nba_archive_10Y.json`
- Git blob SHA: `f5ba0d4f8f729236fdd8883a65189f2d6443338c`
- Object size reported by GitHub: 7,148,928 bytes.
- The repository's MIT licence applies to the scraper/software. It does not explicitly state the odds dataset itself is licensed under MIT.
- Result: DO NOT IMPORT OR REDISTRIBUTE until dataset rights are independently confirmed.

### 2. SportsDataVerse / hoopR NBA archive

- Repository: https://github.com/sportsdataverse/hoopR-nba-data
- Pinned commit used by the downstream NBA archive importer: `7be25dae2ebe5f6027f5343a4ab3195caa61aee5`
- Repository metadata reports licence `Other` / SPDX `NOASSERTION`; the pinned `LICENSE` file only contains year and copyright-holder metadata, not a clear open-data grant.
- The downstream NBA data pipeline describes a The Odds API consensus closing-line parquet archive (spread and total) from SportsDataVerse/hoopR data, 2020 bubble through 2026, but the repository metadata inspected here does not establish an explicit licence for redistribution of the odds records.
- Result: DO NOT IMPORT OR REDISTRIBUTE until the dataset licence/permissions and attribution terms are verified.

### 3. The Lines Monitor

- Public page: https://thefantasymonitor.com/lines/
- It describes closing spread, total and moneyline coverage from 2020-21 through 2025-26 and mentions multiple source licence classes.
- Opening lines and line-movement timestamps are absent according to the page description.
- Exact downloadable files, immutable versions, and row-level attribution were not verified in this audit.
- Result: candidate for further source-level review only; not an approved data feed.

## Safe implementation boundary

Until rights are cleared, V8.0 may:

1. Keep existing historical results and model features already lawfully held in the isolated research database.
2. Build and test data validators using synthetic fixtures and schema-only examples.
3. Test market probability conversion and vig removal using explicitly synthetic example odds.
4. Run score-only model evaluation that does not claim betting ROI, CLV, or market superiority.
5. Record missing market coverage explicitly; never impute a market line from the final score or post-tip data.

V8.0 may not:

- copy raw SBR or SportsDataVerse odds into the project/database without explicit rights;
- describe an MIT scraper licence as an MIT licence for the scraped dataset;
- claim historical CLV, executable prices, or ROI without time-stamped and source-attributed two-sided prices;
- merge experimental data or code into the production branch as a validated betting model.

## Required data contract before any future import

Each market quote must retain:

- source/provider and source dataset identifier;
- source URL, immutable revision or retrieval date, and SHA-256 checksum;
- explicit licence/permission reference and required attribution;
- NBA game ID, home/away team IDs, and game date/time with timezone;
- market type (`moneyline`, `spread`, `total`), side, line/handicap, and decimal/American odds;
- quote timestamp and quote phase (`open`, timestamped update, `close`);
- original raw value, normalized value, and every correction flag;
- match confidence and rejection reason where a row is not accepted.

Rows without verified source rights, quote time, or unambiguous game matching must be quarantined or rejected, not silently loaded.

## Phase 9.8 acceptance tests

- [ ] Dataset rights and attribution verified for each individual source.
- [ ] Immutable source artifact and checksum recorded.
- [ ] Per-season coverage and missingness report generated.
- [ ] One-to-one game matching validated against official game IDs and final scores.
- [ ] Duplicate, outlier, swapped-field, timezone and bubble-date cases tested.
- [ ] No future information leaks into pregame features.
- [ ] Opening and closing quotes are time-ordered and source-attributed.
- [ ] Market-specific chronological holdout and calibration tests pass.
- [ ] CLV/ROI marked NOT CALCULABLE where executable prices or timestamps are absent.

## Current release status

Phase 9.8 completed as a source-rights gate and schema contract only. No new historical odds data has been imported. No model performance improvement is claimed. Moneyline, Spread and Over/Under remain unapproved for V8.0 production pending independently reproducible market validation. The existing V7.8.2 production branch remains unchanged.
