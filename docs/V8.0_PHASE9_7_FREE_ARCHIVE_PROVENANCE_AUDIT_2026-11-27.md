# NBA AI V8.0 Phase 9.7 — Free archive provenance and schema audit

Audit date: 2026-11-27
Branch: `v8.0-phase9.7-archive-provenance-audit`
Scope: read-only source and schema audit. No downloads of odds datasets, no paid endpoints, no production database writes, and no model/release changes.

## Executive decision

A stronger free historical archive candidate was identified: `flancast90/sportsbookreview-scraper`, pinned at commit `1a820e50c6fbd0276cde073c22bfffae78930868`. Its repository declares an MIT licence for the scraper/software and includes a pre-scraped NBA archive. A downstream NBA data pipeline documents that archive as containing opening and closing spread and total lines plus closing moneylines for seasons 2011-12 through 2021-22 (with known exceptions/corrections).

**Do not import the raw odds data yet.** The MIT licence explicitly covers the software and associated software documentation; it does not expressly establish redistribution rights for the underlying sportsbookreview-sourced odds dataset. Keep the data quarantined until the dataset/source rights are confirmed.

## Candidate A — SportsbookReview archive

- Repository: https://github.com/flancast90/sportsbookreview-scraper
- Pinned source commit: `1a820e50c6fbd0276cde073c22bfffae78930868`
- Pinned raw archive path: `data/nba_archive_10Y.json`
- Repository licence: MIT (software licence).
- README describes a pre-scraped data folder for each sport, ranging from 2011 to 2021.
- Independent downstream importer documentation says the NBA archive contains:
  - opening and closing spread;
  - opening and closing total;
  - closing home and away moneylines;
  - team names/nicknames and game dates rather than NBA game IDs.
- Downstream importer documents important data-quality caveats:
  - approximately 7% of rows have closing spread and total values swapped;
  - 2019-20 bubble dates require correction;
  - some values are impossible/outliers and must be nulled;
  - each season's last Finals game is missing a reliable home team and has corrupted lines;
  - team names require a season-aware crosswalk;
  - matching should use teams/date windows and final scores, not exact date alone.

### Rights assessment

The repository's MIT licence grants rights to the software. It does not explicitly state that the underlying odds records scraped from SportsbookReview are independently licensed under MIT or that onward redistribution is permitted. Therefore, software licence != dataset licence. No raw data import or public redistribution is approved by this audit.

## Candidate B — llimllib/nba_data downstream archive pipeline

- Repository: https://github.com/llimllib/nba_data
- Inspected commit: `d3941f7b3105973ef77bf21409eb6bd9c2b65903`
- Relevant source: `pipeline/odds_archives.py`
- Its code pins the SBR archive above and separately pins a SportsDataVerse/hoopR consensus closing-line parquet file.
- The data dictionary describes `betting_lines` as per-game opening/closing spread, total and moneylines by sportsbook or archive from 2012 onward.
- The repository metadata inspected in this audit did not declare a repository-level licence. Its code/data provenance must not be treated as a blanket data redistribution licence.
- The downstream pipeline documents corrections and exclusions, making it a useful schema/matching reference, not an automatic rights clearance.

## Candidate C — The Lines Monitor

- Public page: https://thefantasymonitor.com/lines/
- Page describes NBA coverage from 2020-21 through 2025-26 and closing spread, total and moneyline fields from three source classes described as CC0, CC BY-SA and MIT.
- It explicitly says opening lines and line-movement timestamps are missing.
- Exact downloadable artifacts, immutable revisions, and row-level source/licence attribution were not pinned during this audit.
- Suitable for further investigation as a closing-line benchmark only after exact artifacts and source-specific attribution are verifiable. It cannot by itself establish executable ROI or CLV.

## Impact on the current V8.0 test database

The isolated Neon database currently contains 2,426 SBR rows with two-sided closing moneylines across 2020-21 and 2021-22. It contains no paired opening moneyline prices and no two-sided spread or totals prices in the currently imported SBR rows. This is consistent with the current importer storing only the closing moneyline fields from this source, not the full raw archive's line fields.

No existing rows were modified in Phase 9.7.

## Acceptance gates before import

1. Confirm the legal/data rights for the raw SportsbookReview-sourced dataset, separately from the MIT scraper code.
2. Pin the exact raw archive URL and SHA-256 checksum; preserve the source commit and attribution.
3. Inspect the raw JSON schema and compute per-season row counts and field completeness offline.
4. Validate opening/closing spread and total fields, including known swapped-column and bubble-date corrections.
5. Resolve teams through a season-aware crosswalk; reject unknown or ambiguous team names.
6. Match games one-to-one to NBA game IDs and final scores; reject duplicate, ambiguous, or mismatched rows.
7. Preserve provider/source identifiers, quote-time limitations, missingness, and all correction flags.
8. Import first into a new quarantined research table/artifact, never into production tables.
9. Re-run chronological TEST and untouched FINAL_HOLDOUT against market-only baselines for each market.
10. Keep ROI/CLV marked NOT CALCULABLE unless genuine two-sided executable prices and comparable opening/closing timestamps are present.

## Release status

Phase 9.7 source/provenance audit is documented. It does not resolve the dataset-rights blocker and does not supply a validated predictive edge. Moneyline, Spread and Over/Under remain disabled for V8.0 production. V7.8.2 production remains unchanged.
