# V8.0 Phase 2 — Historical Market Data Source Audit

Audit date: 2026-11-26 (UTC)
Target: isolated V8.0 test branch only. Production website and production database are not changed.

## Decision

A stronger public, openly licensed historical closing-line source has been identified: The Lines Monitor NBA Data Health page.

Source: https://thefantasymonitor.com/lines/

The source reports 7,776 NBA games across 2020-21 through 2025-26, with closing spread and total for all 7,776 games and closing moneyline for 7,774. Its stated inputs are:
- consensus closing spread/total: CC0
- BetMGM closing lines: CC BY-SA 4.0
- OddsPortal average moneyline: MIT

The source reports row-level game matching and score checks, plus flagged/unconfirmed line disagreements. It explicitly says historical opening lines and quote timestamps are unavailable in these free sources.

## Import gates before any write

1. Pin exact source file URLs/commits and preserve license/source attribution per row.
2. Reconcile source game IDs to `nba_game_results` using teams and tip-off date/time; require unique one-to-one matches.
3. Validate final scores against `nba_game_results`; drop mismatches rather than correcting by inference.
4. Validate spread sign convention, total range, American/decimal price parsing, vig removal, pushes and neutral-site handling.
5. Preserve source and disagreement flags. Do not label a consensus average as Pinnacle.
6. Run dry-run counts and duplicate/orphan checks on the isolated branch before committing rows.
7. Keep historical closing-line evaluation separate from true pre-game AI backtests. A closing market line is a benchmark, not an AI prediction.

## Important limits

- These are closing lines; they do not provide reliable historical opening-to-closing movement or historical quote timestamps.
- CLV against a historical opener cannot be computed from this source.
- A model trained with data after the game or with final injury information would leak future information. Backtests must be chronological and pre-tip only.
- The source's public page describes coverage and licensing, but the exact downloadable files and raw schemas still need to be pinned and inspected before ingestion.

## Next implementation step

Build a reproducible, dry-run-first importer for the CC0 consensus spread/total archive and the MIT OddsPortal moneyline archive, map records to the isolated game table, then report exact per-season joins, gaps, duplicate rows, score mismatches and flagged lines. Do not write to production.
