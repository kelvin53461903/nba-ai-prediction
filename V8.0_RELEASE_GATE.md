- [ ] Report sample sizes, confidence intervals, calibration (Brier/log loss/ECE), and performance by season/market.

## Current limitations
The available market history is consensus closing probabilities/lines, not verified executable prices from individual bookmakers. The public multi-provider parquet audit returned HTTP 403. No bookmaker rows have been imported. Earlier same-sample results did not show the AI consistently outperforming the market. Therefore CLV and real-price ROI are not yet established.

## Release decision
**NOT APPROVED FOR PRODUCTION MERGE.** Keep this branch isolated until every mandatory production gate passes. Do not claim betting reliability or positive expected value from accuracy alone.
