## Expanding-window moneyline walk-forward

Each test season is evaluated only after training on all earlier seasons. Test-season labels are not used to fit the model.

| Held-out season | Training games | Test games | Model accuracy | Elo accuracy |
|---|---:|---:|---:|---:|
| 2021-22 | 1,171 | 1,322 | 64.45% | 63.54% |
| 2022-23 | 2,493 | 1,319 | 61.71% | 61.94% |
| 2023-24 | 3,812 | 1,318 | 65.63% | 64.49% |
| 2024-25 | 5,130 | 1,321 | 64.65% | 65.10% |
| 2025-26 | 6,451 | 1,138 | 67.14% | 66.61% |

Across 6,418 held-out games, weighted model accuracy is approximately **64.65%**, versus **64.27%** for Elo. This is a small directional-accuracy difference and does not establish a profitable betting edge. Probability calibration metrics must be considered alongside accuracy.

## Release blockers

1. Obtain lawful, verifiable individual bookmaker historical prices with timestamp, bookmaker, market, line, odds and game identity. The imported SBR archive is not a named bookmaker feed.
2. Validate line and price coverage across multiple seasons for moneyline, spread and totals.
3. Run leakage-safe, season-held-out model comparisons on identical games and identical market timestamps.
4. Calculate CLV using actual executable prices and ROI after vig, pushes, limits and realistic execution assumptions.
5. Demonstrate stability across multiple independent seasons and report confidence intervals; do not optimize thresholds on the final holdout.
6. Verify current Streamlit UI and scheduled workflows, secrets isolation, rollback and production compatibility.
7. Only then create a reviewed pull request and explicitly approve production deployment.

**No ROI, CLV, or reliable betting edge is claimed. V8.0 must remain a test candidate until all release blockers pass.**
