# NBA AI V8.0 Phase 6C — Pre-tip snapshot leakage audit

Date: 2026-11-26
Input: Phase 6C rolling market/Elo artifact, 7,577 score-crosswalked games.
Audit rule: A market snapshot is eligible for pregame modelling only when its timezone-aware timestamp is strictly earlier than the scheduled UTC tip-off.

## Finding

| Check | Rows |
|---|---:|
| Source feature rows | 7,577 |
| Strictly pre-tip snapshot | 1,166 |
| Snapshot at or after tip-off | 6,411 |
| Missing/invalid timezone-aware timestamps | 0 |

Thus 84.6% of the original rows were excluded from pregame modelling. The most common offsets after tip-off were approximately 0.6 minutes, 5 minutes, and 0.7 minutes. A post-tip snapshot is not a valid pregame feature, even if the price resembles a closing line.

## Strict-filter rerun

Workflow: https://github.com/kelvin53461903/nba-ai-prediction/actions/runs/45819648879

- Phase 6C filtered to 1,166 rows and asserted every snapshot < tip-off.
- Same-date result exclusion remained enabled.
- Phase 7B unit tests passed and the model script completed.
- Spread and Totals gates both remained FAIL against the market-only baseline.
- Strict pre-tip splits: Spread TRAIN 548 / VALIDATION 274 / TEST 202 / FINAL_HOLDOUT 128; Totals TRAIN 551 / VALIDATION 275 / TEST 202 / FINAL_HOLDOUT 130.

## Corrective controls

- Phase 6C now rejects rows with invalid timestamps or snapshots at/after tip-off.
- Phase 7B independently rechecks every row and fails closed if any post-tip snapshot remains.
- Tests cover post-tip, at-tip, pre-tip, timezone-naive and timezone-offset cases.
- The original 7,577-row result must not be used as a pregame model performance claim.

## Release decision

This is a material data leakage correction. It does not establish model quality. Continue only with strictly pre-tip sources and independent walk-forward evaluation. Production remains unchanged.
