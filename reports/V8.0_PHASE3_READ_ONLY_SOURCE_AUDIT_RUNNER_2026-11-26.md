# V8.0 Phase 3 — Read-only Source Audit Runner

Date: 2026-11-26
Branch: `v8.0-phase2-historical-market-audit`

## Implemented

- `scripts/v80_phase3_source_audit.py`: downloads two immutable public archives, inspects the consensus Parquet schema/coverage, inspects SBR source fields and market-value availability, and dry-runs an SBR team/date join against the isolated Neon `nba_v80` game table.
- `.github/workflows/v80_phase3_source_audit.yml`: runs automatically on changes to the audit script/workflow on this isolated branch and uploads a JSON artifact.
- The database connection is forced to PostgreSQL read-only mode (`default_transaction_read_only=on`). The script contains no INSERT, UPDATE, DELETE, DDL or production connection.
- The workflow requires the existing `V80_HISTORICAL_IMPORT_DATABASE_URL` GitHub secret. It is used only to read the isolated test branch's game table.

## Deliberate limits

- This workflow is an audit only. It does not insert any historical odds into Neon.
- SBR matching uses team IDs and Eastern game date within one day, then one-to-one nearest-date assignment. Ambiguous candidates and collisions are reported. This is a candidate match, not an accepted final join.
- Source score fields are recorded for inspection; score verification still requires confirming the exact source field names and comparing all rows to the NBA game table.
- The consensus Parquet uses ESPN event IDs. It cannot be joined directly to NBA game IDs; a validated ESPN scoreboard bridge is still required.
- The free Lines Monitor data-health page reports separate CC0 consensus, CC BY-SA BetMGM and MIT OddsPortal datasets. Its page-level coverage statement is not a raw archive URL. Do not assume the sportsdataverse Parquet is the same CC0 source; its own repository licence metadata is NOASSERTION.
- No model backtest, ROI, CLV or production deployment is claimed by this phase.

GitHub Actions artifact: `nba-v80-phase3-source-audit`, containing `source_audit.json` and the pinned source files. The action result must be checked before proceeding. If the secret is absent or the source endpoint fails, the workflow fails closed and no database changes occur.
