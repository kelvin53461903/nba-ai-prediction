## Important limitations

1. `game_id` is an ESPN event ID, not the NBA game ID used in the isolated Neon database.
2. Score-level matching was deliberately NOT performed in Phase 4C. A separately verified ESPN scoreboard event-to-team/date crosswalk is required.
3. This source supports market-line benchmarking only after the crosswalk and final-score validation.
4. No spread/total ROI can be calculated without the actual prices for both sides.
5. No opening lines are present in this file, so it cannot provide opening-to-closing CLV.
6. No game-level source data was written to Neon or production.
