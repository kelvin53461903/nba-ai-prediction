## Features generated

For each home and away team, the table contains:

- games played before tipoff;
- last-5 win percentage, points scored and points allowed;
- last-10 win percentage, points scored and points allowed;
- rest days since the previous game;
- maximum prior-game tipoff timestamp used for audit.

Targets are stored separately: actual home/away score, home win, total points and score margin.

Features use only games with `commence_time_utc < current feature_cutoff_utc`. Games sharing the same tipoff timestamp are excluded from each other's history. First-appearance teams legitimately have blank rolling averages and must be handled by the model pipeline without imputing future information.

## Important limitations

- This is a score-derived team-form feature dataset, not a trained model and not a prediction ledger.
- No historical market odds were used to construct these features.
- The existing `nba_advanced_stats` table is empty in the isolated test database; ORtg/DRtg/Pace features are not included.
- The SBR-derived bookmaker table currently has 2,426 paired closing moneylines but zero paired opening moneylines, spread prices/lines, or total prices/lines. It cannot support complete three-market market-baseline backtests.
- No ROI or CLV can be calculated from this build.
